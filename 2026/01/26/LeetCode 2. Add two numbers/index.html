LeetCode 2. Add two numbers

https://leetcode.com/problems/add-two-numbers/

Difficulty: Medium

Key point: Linked list

This problem is check for linked list

In Python, we use the default class ListNode to store the node and create the linked list.

For this problem, we can breakdown to the small parts:

  1. Get the value of each node for l1 and l2
  2. Add the two value + carry = total and check if there is carry. If so, calculate the carry by // 10 and store it as carry
  3. Calculate the digit by % 10, then store it as digit
  4. Store the digit in result(new linked list) by curr.next = ListNode(digit)
  5. Check if node of l1/l2 still exist, then l1 = l1.next for the next node
