LeetCode 10. Regular Expression Matching

https://leetcode.com/problems/regular-expression-matching/

Difficulty: Hard

Key point: Dynamic Programming - Pattern Matching

This problem checks your ability to implement a regular expression matcher with two special symbols:

  • . matches any single character
  • matches zero or more of the preceding element

We are given two strings s and p, and we need to return True if p matches the entire string s.

Breakdown into small parts:

  1. Understand the matching rules.

    • A character matches itself
    • . matches any one character
    • allows 0 or more of the previous character

  2. Use dynamic programming.

    Let dp[i][j] be True if s[0:i] matches p[0:j].

  3. Initialize a 2D DP table with size (len(s)+1) x (len(p)+1).

    dp[0][0] = True means an empty string matches an empty pattern.

  4. Handle patterns with at the beginning that can match empty strings.

    For example, pattern a* can match an empty string.

  5. Fill the DP table using recurrence:

    • If p[j-1] == s[i-1] or p[j-1] == '.':

      dp[i][j] = dp[i-1][j-1]

    • If p[j-1] == '*':

      • Treat as zero occurrence: dp[i][j] = dp[i][j-2]
      • Or if s[i-1] == p[j-2] or p[j-2] == '.':dp[i][j] |= dp[i-1][j]
