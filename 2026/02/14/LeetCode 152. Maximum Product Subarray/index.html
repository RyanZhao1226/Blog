LeetCode 152. Maximum Product Subarray

https://leetcode.com/problems/maximum-product-subarray/

Difficulty: Medium

Key point: Track both max and min

This is a dynamic programming problem.

The tricky part is that negative numbers can flip the sign, so we must track:

  • the maximum product so far
  • the minimum product so far

Why Track Minimum?

Example:

When we see -2, the max product becomes small.

But if we later multiply by another negative number:

A small negative value × negative → becomes large positive.

So we must track both:

  • cur_max
  • cur_min
