LeetCode 366. Find Leaves of Binary Tree

https://leetcode.com/problems/find-leaves-of-binary-tree/

Difficulty: Medium

Key point: DFS (postorder) + height grouping

This is a classic tree DFS problem.

Instead of actually removing leaves level by level, we can group nodes by their height from the bottom.

Key Observation

  • All leaves have height 0

  • A node’s height is:

  • Nodes with the same height will be removed in the same round

So the problem becomes:

Group nodes by their height (from bottom)

Breakdown

  1. We are given the root of a binary tree.
  2. Use postorder DFS to compute height:
    • process left child
    • process right child
    • compute current node height
  3. Use a list res:
    • res[h] stores all node values with height h
  4. During DFS:
    • If h == len(res), add a new list
    • Append current node’s value to res[h]
  5. Return res.
