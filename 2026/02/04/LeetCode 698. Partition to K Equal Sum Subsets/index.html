LeetCode 698. Partition to K Equal Sum Subsets

https://leetcode.com/problems/partition-to-k-equal-sum-subsets/

Difficulty: Medium

Key point: Backtracking + bucket filling + pruning

This is a classic backtracking problem.

We try to partition the array into k subsets, each with the same sum.

Breakdown

  1. We are given:
    • an integer array nums
    • an integer k
  2. To be able to partition:
    • sum(nums) must be divisible by k
    • each subset sum = sum(nums) / k
  3. Sort the array in descending order:
    • This helps prune invalid paths early
  4. Use backtracking to assign each number to one of the k buckets.
  5. During backtracking:
    • If adding a number exceeds the target subset sum → skip
  6. Pruning optimization:
    • If two buckets have the same current sum, skip duplicate states
  7. If all numbers are placed successfully, return True.
  8. Otherwise, return False.
