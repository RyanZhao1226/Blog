LeetCode 179. Largest Number

https://leetcode.com/problems/largest-number/

Difficulty: Medium

Key point: Custom sorting (string comparison)

This problem looks like a sorting problem, but the key challenge is defining the correct comparison rule.

Breakdown

  1. We are given a list of non-negative integers nums.

  2. We need to arrange them so that they form the largest possible number when concatenated.

  3. Key observation:

    • For two numbers a and b,

      we should compare a + b vs b + a (as strings).

    • Example:

  4. Steps:

    1. Convert all numbers to strings.
    2. Sort them using a custom comparator based on a+b and b+a.
    3. Concatenate the sorted strings.

  5. Edge case:

    • If the largest number is "0", return "0" instead of "000...".
