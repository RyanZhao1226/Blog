LeetCode 40. Combination Sum II

https://leetcode.com/problems/combination-sum-ii/

Difficulty: Medium

Key point: Backtracking + pruning + duplicate handling

This is a classic backtracking problem.

The main challenge is handling duplicates correctly so that the result does not contain repeated combinations.

Breakdown

  1. We are given:

    • candidates: a list of integers (may contain duplicates)
    • target: the target sum

  2. Each number can be used at most once in each combination.

  3. First, we sort the candidates:

    • This helps with pruning
    • This makes duplicate handling possible

  4. Use backtracking (DFS) to explore combinations:

    • Keep track of:
      • current combination (path)
      • remaining sum (remain)
      • current index (start)

  5. Pruning rules:

    • If remain == 0:

      → add current combination to result

    • If remain < 0:

      → stop exploring this path

  6. Duplicate handling:

    • When iterating, if

      candidates[i] == candidates[i - 1] and i > start,

      we skip this element to avoid duplicate combinations.

  7. Continue until all possibilities are explored.

  8. Return the result list.
